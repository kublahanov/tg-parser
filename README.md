# Tg-Parser

Сервис для парсинга каналов Telegram.

## Основные сведения

- **Язык реализации**: PHP.
- **Основной функционал**: Парсинг каналов Telegram с сохранением списка сообщений (в БД), и медиа-контента (в файловой системе).
- **Дополнительный функционал**: Отображение списка чатов и сообщений в виде веб-страницы.
- Работает на базе библиотеки **TelegramApiServer**.
